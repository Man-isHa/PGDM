Binary classification with general features

\[\boxed{x_i\in\mathbb R^d,\qquad y_i\in\{0,1\}}\]
\[\boxed{p(x)=\Pr(Y=1\mid X=x)}\]
\(\Pr(Y=0\mid x)=1-p(x)\), and \(0\le p(x)\le1\).
For now: two classes only.

Why not ordinary linear regression?

\[\hat y=\beta_0+\beta_1x\]
It can output \(\hat y=-0.3\) or \(\hat y=1.4\).
Can these be probabilities?

The logistic model

Scores, the sigmoid and log-odds

Start with a linear score

Feature vector \(x\in\mathbb R^d\).
\[\boxed{z=\beta_0+\sum_{j=1}^d\beta_jx_j}\]
With \(\tilde x=(1,x^\top)^\top\), \(\beta\in\mathbb R^{d+1}\): \(\quad z=\beta^\top\tilde x\)
Problem: \(z\in\mathbb R\), but probabilities lie in \([0,1]\).

The logistic (sigmoid) function

\[\boxed{\sigma(z)=\frac{1}{1+e^{-z}}}\]
  • \(0<\sigma(z)<1\) for every finite \(z\)
  • \(\sigma(0)=\tfrac12\)
  • increases as \(z\) increases

What does the sigmoid do?

Any real score becomes a valid probability.

The logistic regression model

\[\boxed{\Pr(Y=1\mid X=x)=\sigma(\beta^\top\tilde x)}\]
\[p_i(\beta)=\frac{1}{1+e^{-\beta^\top\tilde x_i}}\]
\[\Pr(Y=0\mid x_i;\beta)=1-p_i(\beta)\]

Exercise: scores to probabilities

Scores \(\beta^\top\tilde x=-2,\ 0,\ 2\)
Exercise (2 minutes): compute \(\sigma(\beta^\top\tilde x)\).
\(\beta^\top\tilde x\)−202
\(\sigma(\beta^\top\tilde x)\)0.1190.5000.881
Which scores give \(\hat p>0.5\)?
\(\sigma(\beta^\top\tilde x)>0.5\) exactly when \(\beta^\top\tilde x>0\).

From the sigmoid to the log-odds

\[p=\frac{1}{1+e^{-\beta^\top\tilde x}}\]
\[1-p=\frac{e^{-\beta^\top\tilde x}}{1+e^{-\beta^\top\tilde x}}\]
\[\frac{p}{1-p}=e^{\beta^\top\tilde x}\]
\[\boxed{\log\frac{p}{1-p}=\beta^\top\tilde x}\]
The log-odds is exactly the linear score.

Why is logistic regression a linear model?

\[\log\frac{p(x)}{1-p(x)}=\beta^\top\tilde x=\beta_0+\beta_1x_1+\cdots+\beta_dx_d\]
Probability: not linear in \(x\). Log-odds: linear in \(x\).

What are the odds?

\[\boxed{\operatorname{odds}(p)=\frac{p}{1-p}}\]
Example: \(p=0.8\ \Rightarrow\ 0.8/0.2=4\)
Four times as likely to occur as not.

Exercise: probability vs odds

Exercise (1 minute): odds for \(p=0.2\) and \(p=0.8\)?
\[\operatorname{odds}(0.2)=\frac{0.2}{0.8}=0.25,\qquad\operatorname{odds}(0.8)=\frac{0.8}{0.2}=4\]
Probability and odds are different quantities.

From probabilities to classification

\[\hat p(x)=\sigma(\hat\beta^\top\tilde x)\]
\[\hat y=\begin{cases}1,&\hat p(x)\ge0.5\\0,&\hat p(x)<0.5\end{cases}\]
Decision boundary: \(\ \boxed{\hat\beta^\top\tilde x=0}\)
Other thresholds suit unequal error costs.

Learning \(\beta\)

Bernoulli likelihood and cross-entropy

How do we learn \(\beta\)?

\[\Pr(Y=1\mid X=x)=\sigma(\beta^\top\tilde x)\]
Given labelled data, how should we estimate \(\beta\)?
Recall linear regression:
\[\boxed{\text{choose parameters that maximise the likelihood}}\]

The Bernoulli distribution

\[\Pr(Y=1\mid x)=p,\qquad\Pr(Y=0\mid x)=1-p\]
\[\boxed{\Pr(Y=y\mid x)=p^y(1-p)^{1-y}}\]
\(y=1\): \(\ p^1(1-p)^0=p\)
\(y=0\): \(\ p^0(1-p)^1=1-p\)

Exercise: one observation’s likelihood

The model predicts \(p=0.8\).
Probability of observing \(y=1\)? \(y=0\)?
\[\Pr(Y=1\mid x)=0.8,\qquad\Pr(Y=0\mid x)=0.2\]
High likelihood = high probability on the observed label.

Probability vs likelihood

Probability: fix \(\beta\); how likely is a label?
\[\Pr(Y=y\mid X=x;\beta)\]
Likelihood: fix the data; compare values of \(\beta\).
\[L(\beta)=\prod_{i=1}^nP(y_i\mid X;\beta)\]
The product holds because the samples are independent.
In MLE, \(\beta\) is what we vary.

Likelihood of an entire dataset

\[\boxed{L(\beta)=\prod_{i=1}^n p_i(\beta)^{y_i}[1-p_i(\beta)]^{1-y_i}},\quad p_i(\beta)=\sigma(\beta^\top\tilde x_i)\]
MLE: \(\ \hat\beta_{\mathrm{MLE}}\in\arg\max_\beta L(\beta)\)

Why take the log-likelihood?

\[L(\beta)=\prod_i p_i^{y_i}(1-p_i)^{1-y_i}\]
Logs turn products into sums:
\[\boxed{\ell(\beta)=\sum_{i=1}^n\big[y_i\log p_i+(1-y_i)\log(1-p_i)\big]}\]
\(\log\) is increasing \(\Rightarrow\ \arg\max L=\arg\max\ell\)

From likelihood to a loss function

Minimise the negative log-likelihood, averaged:
\[\boxed{\mathcal L(\beta)=-\frac1n\sum_{i=1}^n\big[y_i\log p_i+(1-y_i)\log(1-p_i)\big]}\]
Binary cross-entropy (log loss).

Cross-entropy for one observation

\[\boxed{\mathcal L_{\rm BCE}(y,p)=-y\log p-(1-y)\log(1-p)}\]
\[\mathcal L(1,p)=-\log p,\qquad\mathcal L(0,p)=-\log(1-p)\]
When is the loss close to zero?

A confident correct prediction

True label \(y=1\); model predicts \(p=0.9\).
\[\mathcal L(1,0.9)=-\log0.9\approx\boxed{0.105}\]
High probability on the correct label: small loss.

A confident wrong prediction

True label \(y=1\); model predicts \(p=0.01\).
\[\mathcal L(1,0.01)=-\log0.01\approx\boxed{4.605}\]
Confident mistakes are punished heavily.

Compare two predictions

True label \(y=0\). Which loss is smaller?
\(p_A=0.1\quad\text{or}\quad p_B=0.8\)
\[\mathcal L(0,0.1)=-\log0.9\approx0.105\]
\[\mathcal L(0,0.8)=-\log0.2\approx1.609\]
Model A puts more probability on the observed label 0.

Can we solve for \(\hat\beta\) in closed form?

The log loss as a function of \(\beta\):
\[\mathcal L(\beta)=-\frac1n\sum_{i=1}^n\Big[y_i\log\sigma(\beta^\top\tilde x_i)+(1-y_i)\log\big(1-\sigma(\beta^\top\tilde x_i)\big)\Big]\]
Exercise (3 minutes): set \(\nabla_\beta\mathcal L=0\) and solve for \(\beta\).
\(\beta\) sits inside \(\sigma(\cdot)\) in every term: the equations are nonlinear in \(\beta\).
No closed-form solution, unlike OLS.

The log loss is convex

A single bowl in \(\beta\)-space.
No local traps: any minimum is the global minimum.
\(\nabla^2\mathcal L=\frac1n\sum_ip_i(1-p_i)\,\tilde x_i\tilde x_i^\top\succeq0\)
So we can walk downhill to \(\hat\beta\).
Log loss over \((\beta_0,\beta_1)\) for a 1-feature dataset. Drag to rotate.

Gradient descent: the idea

Slope at the current \(\beta\): the gradient.
Step against it, scaled by the learning rate \(\eta\):
\[\boxed{\beta^{(t+1)}=\beta^{(t)}-\eta\,\nabla_\beta\mathcal L\big(\beta^{(t)}\big)}\]
Repeat. Steps shrink as the slope flattens.
Stop when \(\nabla\mathcal L\approx0\).

Can we minimise cross-entropy with calculus?

\(p=\sigma(z),\ z=\beta^\top\tilde x\)
\[\boxed{\frac{dp}{dz}=p(1-p)}\]
\[\mathcal L(y,p)=-y\log p-(1-y)\log(1-p)\]
What is \(d\mathcal L/dz\)?

A useful gradient identity

\[\frac{d\mathcal L}{dz}=\Big(-\frac yp+\frac{1-y}{1-p}\Big)p(1-p)\]
\[\boxed{\frac{d\mathcal L}{dz}=p-y}\]
\(p>y\): score pushed down

Gradient with respect to the coefficients

Since \(z_i=\beta^\top\tilde x_i\): \(\ \nabla_\beta z_i=\tilde x_i\)
\[\boxed{\nabla_\beta\mathcal L=\frac1n\sum_{i=1}^n\big[\sigma(\beta^\top\tilde x_i)-y_i\big]\,\tilde x_i}\]
Prediction error times input, averaged: plug this into the update rule.

Choosing the learning rate \(\eta\)

Too small: safe but slow
Just right: fast and stable
Too large: overshoots or diverges
In practice: try a few values on a log scale (0.001, 0.01, 0.1, 1), or decay \(\eta\) over time.

Softmax regression

Beyond two classes

So far: \(Y\in\{0,1\}\).
What about \(K>2\) classes? \(\quad\boxed{Y\in\{1,\ldots,K\}}\)
🚗car

One score for each class

\[\boxed{z_k(x)=\beta_k^\top\tilde x,\qquad\beta_k\in\mathbb R^{d+1}}\]
Need \(\ 0\le p_k(x)\le1,\quad\sum_{k=1}^Kp_k(x)=1\)
How do we turn \(K\) scores into probabilities?

The softmax function

\[\boxed{p_k(x)=\frac{e^{z_k(x)}}{\sum_{j=1}^Ke^{z_j(x)}}}\]
Every \(p_k>0\), and they sum to 1.
Multinomial (softmax) logistic regression.

Binary sigmoid is a softmax special case

Two classes: \(z_0=0,\ z_1=z\)
\[\Pr(Y=1\mid x)=\frac{e^z}{e^0+e^z}\]

Limitations

Where logistic regression struggles

Limitation 1: linear decision boundaries

\[\hat y=1\iff\beta^\top\tilde x\ge0\]
\[\boxed{\beta_0+\beta_1x_1+\cdots+\beta_dx_d=0}\]
A hyperplane.
What if no hyperplane separates the classes?

Exercise: the XOR pattern

\(x_1\)\(x_2\)\(y\)
000

Can one straight line separate the classes?
No. XOR is not linearly separable.

How can we model nonlinear patterns?

Linear in the chosen features. Add \(x_1x_2\):
\[z=-1+2x_1+2x_2-4x_1x_2\]
\(x_1\)\(x_2\)\(z\)\(\hat y\)
00−10
0111

11−10
Feature engineering can make nonlinear tasks linearly separable.

Limitation 2: perfect separation

Labels satisfy \(y_i=x_i\), \(x_i\in\{0,1\}\).
Scores \(z_i=t(2x_i-1)\): each label gets probability \(\sigma(t)\).
As \(t\to\infty\), the likelihood \(\to1\).
A finite MLE need not exist.

Other practical limitations

  • Misspecification: true log-odds may not be linear in the features.
  • Probability quality: predictions may be poorly calibrated.
  • Decision costs: 0.5 need not be the best threshold.
