AND gate: one possible answer

w1 = 1,   w2 = 1,   b = −1.5
ŷ = 1[x1 + x2 − 1.5 ≥ 0]

Only the bias changed compared with OR: the line slides, it doesn’t turn.

Instead of guessing: can we learn the weights?

ŷ = 1[w⊤x + b ≥ 0]
w ← w + η(y − ŷ)x
b ← b + η(y − ŷ)

η > 0 is the learning rate. Nothing changes when the prediction is right.

Perceptron learning algorithm

  1. Initialize w = 0, b = 0.
  2. For each labeled example (x, y), predict ŷ.
  3. If wrong, update w and b.
  4. Repeat until convergence, or a stopping limit.

When does this algorithm converge?

When a straight line can separate the classes.

One update, worked out

Training sample: x = (0, 0), y = 0

ŷ = 1[0 ≥ 0] = 1

Wrong prediction, so w = (0, 0), b = −1

Only the bias changes, because the inputs are zero.

A problem: the XOR gate

Can one straight line separate the classes?

Why a single perceptron fails on XOR

(0, 0) ↦ 0⇒b < 0 (1, 0) ↦ 1⇒w1 + b ≥ 0 (0, 1) ↦ 1⇒w2 + b ≥ 0 (1, 1) ↦ 0⇒w1 + w2 + b < 0

The middle two give w1 + w2 + b ≥ −b > 0. Contradiction.

The multilayer perceptron (MLP)

A hidden layer solves XOR

XOR = OR and not AND. Click x1 or x2 to switch an input on or off.

Forward propagation through two layers

h = φ(W1x + b1)
ŷ = ψ(W2h + b2)

Each layer applies an affine map, then an activation.

What if there are no nonlinear activations?

h = W1x + b1,   ŷ = W2h + b2
ŷ = W2(W1x + b1) + b2
ŷ = (W2W1)x + (W2b1 + b2)

A stack of affine layers is still one affine layer.

Three affine layers, one equivalent layer

Both networks give the same output for every input. Only the weight values differ.

Nonlinearity changes everything

ŷ = W2 φ(W1x + b1) + b2

A nonlinear φ stops the layers collapsing into one affine map.

Which activation should we use?

Sigmoid and tanh

Sigmoid

σ(x) = 11 + e−x

Tanh

tanh(x)

Saturation and small gradients

σ′(x) = σ(x)(1 − σ(x))

Far from zero, both σ′(x) and tanh′(x) are close to 0.

Small gradients can make deep networks hard to train.

Tanh saturates too

tanh′(x) = 1 − tanh2(x)

Its gradient peaks at 1, four times the sigmoid’s 0.25, and its output is centred on zero.

Far from zero the gradient still vanishes.

ReLU: a single kink

ReLU(x) = max{0, x}

Flat for x < 0; linear for x > 0.

Several ReLUs: several kinks

f(x) = ReLU(x)
    − 2 ReLU(x − 1)
    + ReLU(x − 2)

Three ReLUs build a tent-shaped function.

More ReLUs: bend the line to fit any curve

Why stacking ReLUs is powerful

A single ReLU has one kink.

A weighted combination makes many kinks.

Composing layers makes increasingly intricate piecewise-linear functions.

Nonlinearity + composition = expressive models.

Layer by layer: the decision boundary bends

Universal approximation theorem

Under suitable assumptions, a neural network with

one sufficiently wide hidden layer

can approximate any continuous function

arbitrarily well on a compact domain.

A statement about representational capacity, not trainability.

What universal approximation does not promise

  • A small number of neurons
  • That gradient descent finds the right weights
  • Generalization to unseen data
  • Efficient computation or sample complexity

Depth versus width

Wide and shallow

Narrow and deep

For some functions, depth can save exponentially many units.

Why depth can help: repeated composition

f1 = T(x),   f2 = T(T(x)),   f3 = T(T(T(x))),  …  where T is the tent, built from 2 ReLUs

Recap: the big ideas

  • A perceptron learns a linear decision boundary.
  • XOR motivates hidden layers.
  • Without activations, stacking layers adds no expressivity.
  • ReLU networks build complex piecewise-linear functions.
  • Width enables approximation; depth can enable efficiency.
