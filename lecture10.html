MLP forecasting vs. MLP sequence generation

  • The window length is fixed in advance.
  • Prediction errors can accumulate as predictions are fed back.
  • Natural language and long-term trends can depend on much older context.

What should a sequential model do?

  1. Read inputs one at a time.
  2. Maintain a summary of the past.
  3. Update that summary whenever a new input arrives.
  4. Use the summary to predict the next element.
